# AI and Technology Website

A responsive single-page website with tabbed navigation, a live topic search, and a validated contact form. Built with plain HTML, CSS, and JavaScript, with no dependencies.

## Features
- Tabbed navigation: Home, AI, Technology, Tools, and Contact
- Live search filter for topic cards on the Home tab
- Contact form with name, email, and message validation
- Responsive layout that works on phones, tablets, and desktops
- Automatic footer year

## Project Structure
- `index.html`: the complete website, including HTML, CSS, and JavaScript

## Built With
- HTML5
- CSS3
- JavaScript (vanilla, no frameworks or libraries)
